# Security policy

Do not post secrets, unredacted device identifiers, private diagnostics or crash dumps in public issues. When a repository is published, use GitHub private vulnerability reporting if the maintainer has enabled it; otherwise request a private reporting channel without disclosing exploit details publicly.

AudioBridge does not need administrator privileges for normal playback, does not install drivers/services/certificates and does not upload diagnostics. Treat any distribution requesting unrelated credentials, protection disabling or certificate trust changes as outside this project's documented behavior.

Only the current preview is intended to receive maintenance. No response-time guarantee is made. Binaries are unsigned; checksums detect accidental changes but do not independently establish publisher identity.
